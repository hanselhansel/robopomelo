# RoboPomelo

An open-source local tool for thinking through warehouse AMR deployments and producing a traceable engineering handoff.

Implementation is in progress. The npm release is not yet available.

RoboPomelo v1 will provide a local browser application, a complete CLI and terminal wizard, and model-agnostic Agent Skills. It will help engineers expose needs, problems, challenges and risks; define material flows, KPIs and requirements; and prepare acceptance plans and portable review packages.

Read the [approved design](docs/superpowers/specs/2026-09-05-robopomelo-design.md) and [delivery roadmap](docs/superpowers/specs/robopomelo/delivery-and-roadmap.md).

RoboPomelo is free and open source under Apache-2.0. It does not control robots or certify a deployment's physical safety or performance.
