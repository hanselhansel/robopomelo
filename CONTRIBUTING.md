# Contributing to RoboPomelo

Start with a public issue or pull request. Explain the problem, proposed behavior, evidence and compatibility impact. Read the [contributor guide](docs/contributing.md) and [governance policy](docs/governance.md).

Contributions use the repository's [Apache-2.0 license](LICENSE). Sign off your commits under the Developer Certificate of Origin 1.1. No separate contributor license agreement is required. The [contributor guide](docs/contributing.md#license-and-sign-off) explains the sign-off.

Keep customer material, facility details, credentials and application session links out of public reports. Use a small fictional or sanitized reproduction that you have permission to share. Report vulnerabilities through [SECURITY.md](SECURITY.md), not a public bug report.

Work on a branch. Include relevant tests and documentation. AI-assisted contributions face the same validation, provenance and review requirements as other work.
